# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/arnoulR/Whispering/security/advisories/new) when available. If it is unavailable, ask the maintainer for a private reporting channel without disclosing vulnerability details publicly.

Whispering 0.1.0 is a prerelease with no guaranteed support or response time. Build checks and signatures are not a security audit.

Do not include private recordings, transcripts, credentials, user profiles, or machine-specific evidence in public reports.
