Whispering — quick start
=======================

1. Extract the whole Whispering folder to a local drive.
2. Open Whispering.exe. The model is already included.
3. Choose your microphone in Settings if the Windows default is not right.
4. Press Ctrl+Shift+Space to start. Speak. Press again to transcribe.
5. Text is typed into your destination app and saved in Dictation or History.

If transcription fails:
Open History → Retry, or Export audio to keep the recording.
The latest ten recordings are retained for 24 hours by default.
The eleventh recording replaces the oldest, including failed recordings.
Change expiry in Settings. Cleanup runs while open or at next launch.

Typing into the application where you started recording is enabled by
default for new profiles. Place the cursor there before recording. Existing
profiles keep their choice. You can disable automatic typing in Settings.

Keep Whispering open or minimized to use the shortcut. Closing it quits.
Recordings and audio files can be up to 60 minutes long.
Read aloud uses a Microsoft voice already installed in Windows.

Microphone blocked? In Windows Settings, enable microphone access for
desktop applications under Privacy & security → Microphone.

No internet or account is needed. Keep models/ and the DLL files alongside
Whispering.exe. Do not move just the EXE. Use local folders for exports if
you want to avoid cloud sync. Data is saved in %LOCALAPPDATA%\Whispering.

This is an unsigned local build. Check that you trust its source before
running it. See README.md for details, privacy boundaries, and source build
instructions.
